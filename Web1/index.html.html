Acerca de esta página

Es una página estática de pruebas. No guarda datos ni consulta ninguna base de datos: lo único que cambia entre servidores es el número y el color.

Existe una copia idéntica en el otro servidor, con otro número y otro color, para que se note de inmediato cuál respondió.

Cómo probar

1

Abre la dirección del sitio en el navegador.

2

Fíjate en el número grande y en el color de la banda superior.

3

Pulsa Recargar página varias veces.

4

Si el número cambia, el tráfico se está repartiendo entre los dos servidores.

Contacto

Si algo no responde como esperas, revisa primero que el servicio web esté activo en el servidor 1 y que el puerto esté abierto.
